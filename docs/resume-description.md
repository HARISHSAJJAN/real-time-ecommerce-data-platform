# Resume Description

## Project Title

**Real-Time E-Commerce Data Platform** - Kafka, Spark Structured Streaming, StarRocks & Trino

## Resume Bullets

- Built a real-time data pipeline processing e-commerce clickstream events
  through Apache Kafka and PySpark Structured Streaming, with watermarked
  deduplication and windowed aggregation writing to a StarRocks OLAP
  warehouse.
- Designed a star-schema-inspired analytical data model in StarRocks
  (dimension, fact, and pre-aggregated metric tables using Primary Key and
  Duplicate Key table models) queried through Trino's distributed SQL engine.
- Implemented a FastAPI analytics service with a repository/service layered
  architecture and a Streamlit dashboard, backed by automated data-quality
  validation, a Kafka dead-letter topic, and a 32-test Pytest suite covering
  generation, transformation, and API logic.

## Technologies

Python, Apache Kafka, PySpark (Structured Streaming), StarRocks, Trino,
PostgreSQL, FastAPI, Streamlit, Docker & Docker Compose, Pydantic, pytest,
SQL.
